Use the **3 imported reference images** as the exact structural reference for the product. Keep the same core screens, hierarchy, navigation logic, content placement, and overall mobile app flow, but redesign them into a **premium 3D animated mobile AI interface** with a unique NOVA identity.

The final result must feel like a real polished production app, not a generic AI concept, not a ChatGPT clone, and not an overdecorated sci-fi dashboard.

Create these 3 screens:

1. **Main AI Chat Screen**
2. **Navigation / Chat History Sidebar**
3. **Login / Sign In Screen**

All 3 screens must use the **same visual system, same 3D depth language, same animation language, same typography, same color palette, and same component styling**.

The interface should feel modern, futuristic, elegant, human, intelligent, and premium.

# 3D DESIGN LANGUAGE

Convert the imported flat UI into a **subtle 3D interface**, not cartoon 3D.

Use dimensional layering carefully.

The interface should feel as if the controls are physically floating a few millimeters above the background.

Use:

* subtle depth
* soft realistic shadows
* ambient occlusion
* slight surface highlights
* soft edge lighting
* realistic glass refraction
* layered elevation
* gentle perspective
* soft inner shadows
* floating buttons
* tactile raised surfaces

Avoid:

* huge extruded objects
* toy-like buttons
* claymorphism
* chunky plastic
* excessive chrome
* metallic sci-fi surfaces
* exaggerated perspective
* gaming dashboard look

Think of premium smartphone hardware translated into software.

Elements should feel refined like frosted glass, polished dark ceramic, soft matte surfaces and subtle illuminated edges.

# BACKGROUND

Use a deep near-black forest background.

Do not use a totally flat black fill.

Create extremely subtle depth in the background with:

* soft dark radial gradients
* blurred emerald atmospheric lighting
* faint organic 3D wave forms
* very subtle flowing depth layers
* low-opacity translucent shapes
* soft vignette
* gentle light diffusion

The background must remain quiet enough that text stays extremely readable.

Do not add stars, galaxies, obvious particles, futuristic grids, matrix code or random sparkles.

A few tiny ambient light particles can appear only if extremely subtle.

---

# GLOBAL 3D PERSPECTIVE

The UI should remain readable as a normal mobile interface.

Do not rotate the entire phone interface into an extreme 3D angle.

Use front-facing mobile layouts with tiny depth movements.

Each screen can have multiple depth planes:

* background plane
* content plane
* floating control plane
* modal/drawer plane
* focused element plane

Depth should be visible mostly through lighting and shadow rather than large geometric perspective.
